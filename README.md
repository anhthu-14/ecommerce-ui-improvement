# E-commerce UI Improvement – Demo Mall

## 1. Giới thiệu

Đây là bài tập cá nhân môn **Phát triển ứng dụng Thương mại điện tử**, tiếp tục phát triển giao diện website từ Buổi 1. Website **Demo Mall** là giao diện minh họa bán hàng trực tuyến, được xây dựng bằng HTML5 và CSS3.

Bài tập tập trung vào việc trình bày danh sách sản phẩm rõ ràng, sắp xếp bố cục hợp lý và hỗ trợ hiển thị trên nhiều kích thước màn hình.

## 2. Website tham khảo và khu vực cải tiến

- **Website tham khảo:** Shopee Việt Nam
- **Đường dẫn:** https://shopee.vn/
- **Khu vực tham khảo:** Danh sách sản phẩm và cách hiển thị thông tin sản phẩm.
- **Khu vực thực hiện:** Giao diện danh sách sản phẩm của Demo Mall.

> Đây là website minh họa độc lập, không phải bản sao hoàn chỉnh của Shopee và không kết nối với hệ thống Shopee.

## 3. Công nghệ và kỹ thuật đã thực hành

- **HTML5:** Sử dụng các thẻ như `header`, `nav`, `main`, `section`, `article` và `footer` để tổ chức nội dung.
- **CSS3:** Sử dụng selector, class và các thuộc tính định dạng giao diện.
- **Box Model:** Thực hành `margin`, `padding` và khoảng cách giữa các thành phần.
- **Flexbox:** Sắp xếp và căn chỉnh các thành phần trên cùng một hàng.
- **CSS Grid:** Sắp xếp danh sách sản phẩm thành nhiều cột và hàng.
- **Responsive Design:** Sử dụng media queries để điều chỉnh bố cục theo kích thước màn hình.
- **Hình ảnh:** Sử dụng `img`, thuộc tính `alt` và `object-fit` để hiển thị hình ảnh sản phẩm.
- **Trạng thái tương tác:** Sử dụng `:hover` và `:focus-visible` cho các thành phần phù hợp.

## 4. Các thay đổi đã thực hiện

- Xây dựng giao diện Demo Mall với danh sách sản phẩm mẫu.
- Trình bày tên sản phẩm, giá khuyến mãi, giá gốc, mức giảm giá và các thông tin liên quan.
- Sử dụng CSS Grid để bố trí các thẻ sản phẩm.
- Sử dụng Flexbox để căn chỉnh các khu vực giao diện.
- Điều chỉnh khoảng cách bằng `margin` và `padding`.
- Bổ sung mô tả `alt` cho hình ảnh sản phẩm.
- Kiểm tra và chỉnh sửa CSS để mã nguồn gọn gàng, dễ bảo trì hơn.

## 5. Cách chạy website

1. Tải hoặc sao chép repository về máy tính.
2. Mở thư mục dự án bằng Visual Studio Code.
3. Mở file `index.html` bằng trình duyệt, chẳng hạn Google Chrome.
4. Kiểm tra giao diện trên màn hình máy tính và sử dụng Chrome DevTools để thử các kích thước màn hình khác.

**Lưu ý:** Đảm bảo file CSS và hình ảnh được lưu đúng vị trí, đồng thời các đường dẫn trong HTML trỏ đến đúng tệp tương ứng.

Website chỉ xây dựng giao diện bằng HTML và CSS, không có backend hoặc cơ sở dữ liệu.
